## Main
El jupyter notebook donde se encuentran todos los gráficos y los códigos referenciados desde el informe. 

## Instalar los requerimientos: 
pip -m venv .venv 
pip install -r requirements.txt

## Usarlo con jupyter 
Una vez:
python -m ipykernel install --user --name=.venv --display-name="Python (.venv)"

Luego en jupyter notebook: Kernels->change kernel->python(.venv)
